How to order through iTaoBuy

  1. Open a CAFANS product page and check the original listing for stock, measurements and seller terms.
  2. Select iTaoBuy in the buying options if it is available, or copy the original listing URL and check whether iTaoBuy accepts it.
  3. If warehouse QC photos are available, compare them with your saved option. Check the size label, color and condition before approving shipment.
  4. Compare shipping quotes for the same destination and parcel dimensions. Ask which weight the carrier uses for billing and which fees the quote includes.
